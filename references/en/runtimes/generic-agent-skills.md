# Generic Agent Skills Runtime Contract

Use only for a host that claims Agent Skills directory compatibility and lacks a dedicated contract. Read current primary documentation and local help; do not invent commands.

## Installation
Confirm the host loads a directory containing a YAML-frontmatter `SKILL.md`. Copy the complete root tree to its documented user/project directory as `delivery-harness`. Single-file hosts or hosts that discard relative resources are incompatible.

## Discovery and invocation
Use the host list/inspect/parse action to confirm `name: delivery-harness`; use its explicit syntax. Put the English [generic block](../../../assets/en/restricted-runtime-entry.block.template.md) only in a documented persistent project instruction file.

## Arrival verification
Verify manifest/hashes, frontmatter/links, host listing plus invocation, and two fresh-session sequence trials for any auto-load claim. Without runtime evidence, report only “files deployed; runtime unverified.”

## Update
Back up, replace all four items, clear only documented skill caches, and rerun discovery/arrival verification.

## Uninstall and rollback
Remove or unregister only `delivery-harness`, update its project entry block, and restore the complete prior tree for rollback.

## Known boundaries
Markdown compatibility is not Agent Skills compatibility. Metadata support, precedence, reload, prefixes, and trust are not standardized. Do not mark support verified without primary documentation and runtime evidence.
