# 项目文档的收敛与安全续行

在接入已有长文档、节点结束、交接、候选摘要超预算或发现重复事实时读取。普通启动按 [核心](core.md) 读取，不展开本页及历史。验收标准是下一位执行者能安全继续，且默认读取量随历史增长保持可控。

按需入口：[归属](#ownership) · [读取](#reading) · [触发](#triggers) · [整理](#procedure) · [恢复](#recovery) · [验证](#verification)。

<a id="ownership"></a>
## 一项事实，一个维护位置

沿用 overlay 已解析的唯一来源；表中名称是默认职责，不要求重命名或创建空文件。

| 文档 | 保留内容 | 更新方式与软预算 |
|---|---|---|
| `state.md` | 目标资产/作用域、当前节点、本动作授权、未关闭门、必要限制、未知结果/在途任务、唯一下一动作与恢复入口 | 替换当前摘要；格式与≤80 物理行见 [H3](hard-constraints.md#h3)，尽量≤5 KiB；token 另计 |
| `process.md` | 过程索引、与续行有关的重要历史节点、最新整理回执入口 | 约30行；替换索引，旧明细和旧索引归档 |
| 证据摘要 | 已证实结果、对象版本/批次、适用范围、限制、精确原始回执入口 | 约50行；替换已过期摘要；原始回执按批次保留 |
| 产物 README | 目录用途、最后已登记批次、保留规则、批次清单和恢复入口 | 约30行；旧批次明细下沉，不累计逐文件历史 |
| 基线、overlay、地图与导航 | 稳定规则、唯一来源路径、文件职责和读取触发 | 变化时更新；结果、活动阻塞和授权只链接 |
| lessons | 有证据且影响未来做法的经验、适用条件、重审条件 | 按主题替换/合并；失效经验归档，按任务读取 |

规格与计划保存批准范围、步骤和验收，不接管实时进度。已消费/撤销/过期授权是历史事实；其仍限制下一动作的部分必须留在 state。若经验已提升为基线规则，lessons 只留理由与规则入口，不再维护另一版规则。

已有追加式系统不能改成索引时，复用其可验证的分段/查询/分页入口，在 overlay 定义默认读取范围及归档方式；保留原记录的编号和语义，不另建可写状态或静默改写系统。

<a id="reading"></a>
## 默认读取与停止展开

默认只读生效的项目规则、overlay 的启动摘要/硬约束/唯一来源字段、唯一 state，以及当前动作确实需要的规则条款。`process.md`、证据摘要、产物 README、lessons 和历史都不是整套启动必读。overlay 的指针表示可定位，不表示递归读取。

| 当前需要 | 补充读取与停止条件 |
|---|---|
| 判断下一动作能否执行 | state 中目标、授权、门、未知结果和在途任务；只有来源不明/冲突/变化才展开对应原文 |
| 核实某项结论 | 该证据摘要的具体项，再读它指向的版本/批次回执；证据范围已足够即停 |
| 取回或清理产物 | 该任务 README 及命中的批次清单、保留决定和恢复入口 |
| 解释过去的决定或错误 | process 索引命中的历史编号/章节；不从首批回放所有过程 |
| 采用既有经验 | lessons 命中的主题及必要证据；涉及授权仍回到 state 与原授权 |
| 恢复整理中断 | state 的整理批次/阶段与恢复入口，再读该批次清单；按下节恢复，不直接执行历史命令 |

保留稳定记录编号/显式锚点；行号仅作定位辅助。若所需段落不能单独可靠读取，就读完整规则单元；冲突、截断或无法核实来源时扩大读取，不能为预算跳过必要条件。已读且未变的内容复用；不把精简后的文件当成已从当前对话卸载旧文本。

<a id="triggers"></a>
## 什么时候整理

每次状态更新直接替换当前字段；只在新事实影响范围、授权、门、限制、恢复或未来做法时增加持久记录。常规成功命令、重复测试过程和“无新发现”不生成新历史条目；证据条目只登记 [H1](hard-constraints.md#h1) 的三类。

节点结束、交接、接入已有项目、任一候选摘要超预算或事实在多处重复时，检查相关文档是否需要收敛。只处理发生实质变化或确有历史负担的文件；没有变化就复用原回执，不制造新时间戳、快照或整理日志。历史总量可增长，默认读取集合不随批次数增长。

体量都是软预算：先外移重复和已完成历史，必要安全信息仍超限就保留并注明原因及后续动作。不能截断授权/风险、拼接超长行、隐藏内容，或把超限记为预算通过。

<a id="procedure"></a>
## 先保护原文，再替换摘要

1. **确认范围与写入方。** 解析 overlay 的原有路径、存储/隐私策略和恢复位置，核对目标及父路径类型、权限、符号链接/重解析点边界。盘点在途任务和其他写入者；无法协调共享写入时只准备候选，不覆盖活动文件。
2. **保存不可变原文。** 使用项目已有历史位置；没有时按需建立 `.delivery/history/<batch>/`。保留待改文档原字节和相对目录结构，清单登记原路径、快照路径、源版本、字节数和 SHA-256；回读副本并逐文件比对。保留相对链接所需依赖，或在清单明确其原解析基准和可验证恢复映射；未解析的必要依赖不能标为可恢复。
3. **标明历史而不改原件。** 在批次 README/清单标记“历史记录，不是当前授权”，并在所有指向快照的导航文字标明历史。不要把警告插入已哈希的原文。批次必须能独立识别其历史身份；直接打开原文时先读批次说明。敏感材料沿用获准受限存储，忽略规则不是权限控制，也不是备份。
4. **提取续行必需信息。** 对照原件逐项保留目标资产、有效授权的来源/动作/范围/有效条件、有限次数的已用/占用/剩余、未关闭门和解除条件、失败限制、未知结果、并行任务标识/负责者/作用范围/回执、恢复入口。唯一下一动作指接手者的下一动作，不抹掉仍在运行的其他任务。
5. **准备替换与中断入口。** 候选摘要放在非活动位置；核对链接及必要字段后，在唯一 state 中登记本批次整理未完成、阶段和恢复入口。多文件不能原子替换时，先写其他文档，最后写经核对的新 state 并关闭整理门。记录预期版本/哈希；包括本次写入的整理标记在内，每次替换前检查来源未被其他写入者修改。发现漂移先合并新事实再验证，不覆盖并行结果。
6. **替换与最小回执。** 复验原文校验、引用/锚点、字段连续性和文档差异后完成切换。整理回执只记批次、来源版本、归档/校验入口、变更文件、读取量前后值、必要例外和恢复方法；明细放批次记录，process 只保留最新回执链接。正常整理不删除原件或历史，也不重新要求已覆盖的授权。

历史明细按阶段/任务/批次分段；历史目录的总索引也只作按需路由，不把每一批的摘要复制到活动索引。原证据和原授权的精确来源保留；摘要只作为入口，不能把模型改写当作原始批准。

<a id="recovery"></a>
## 授权连续性与失败恢复

有次数限制或不能安全重复的副作用，执行前在唯一 state 持久记录操作标识和占用/进行中状态，沿用原授权的消费口径。发出后结果未知时，不因超时或缺回执返还次数，不自动重试；先核实该操作及在途工作。平台已验证的幂等机制可以按其契约复用原标识，不能自行假定幂等。

归档写入、回读、哈希、引用或必要字段验证失败时保留原文；未完成切换就保持整理门未关闭，下一动作是核实当前落盘版本并完成或恢复本批次。只暂停依赖这些不确定信息的动作，独立且已获准的工作可继续。

恢复旧快照只恢复材料，不恢复当时的权限。先核对最新授权及随后发生的消费、撤销、过期与操作回执，再重建有效 state；不能用旧快照的“剩余一次”重放已执行动作。无法确定时记录未知并阻断相关副作用，不假定成功、失败或重新获得授权。

<a id="verification"></a>
## 只验证本次变化需要的证据

纯文档整理检查：原文/清单 SHA-256 一致；保留路径与锚点可解析；必要状态字段和未知/在途事项未丢；有效授权未扩大；不存在第二份活动状态；实际差异只含预期文档。没有应用产物/行为变化时，不重复应用全量测试；Skill 规则升级仍需相应的行为场景验证。

比较相同读取任务的默认文件/段落集合、实际读取字节和物理行；token 使用同一已知 tokenizer 实测，缺工具则明确未测。分别报告基线与整理后值，宿主自动注入、工具输出和历史重读另计。字节减少不等于 token 同比减少；不以固定节省比例或文件更短替代验收。

交接者须能从默认入口确定目标、当前允许动作、未关闭门、未知与在途工作、唯一下一动作和恢复入口；复核证据只需打开对应来源。至少用长历史、一次性操作结果未知、旧快照恢复、并行更新和整理中断检查这一点；场景模拟不能冒充生产/真实运行时证据。

新项目按职责选用[过程索引](../assets/process-index.template.md)、[证据摘要](../assets/evidence-summary.template.md)和[产物 README](../assets/artifact-readme.template.md)模板；既有项目在原位置按以上顺序迁移，不建立平行的一套。
