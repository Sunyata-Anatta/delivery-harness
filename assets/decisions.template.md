# 负责人决策登记

规则的新增、补充和取代都先在这里登记一个 D 编号，规则表和执行文件（AGENTS.md 等）只引用编号，不复制全文。
每条决策写成可判定的文字，不用“适度”“必要时”这类无法判定的词；硬约束必须写明机械检查。
同一条规则第二次被违反时，把违反次数改为 2，并把它升级为带检查的硬约束；不能再追加说明文字。
基线版本只因门结论、生产或现场变更、失败根因或这里的新决策而改版，纯措辞调整不改版本。
